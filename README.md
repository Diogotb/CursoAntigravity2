### Configurando o GIT e o GITHUB

Conectar Git ao GitHub, digitar o seguinte Comando no bash/cmd:

`git config --global user.name "SeuUserName"`

`git config --global user.email "seu@email.com"`

confirmar com o comando:
`git config --list`
